Ticket photos

In the default open-source build, ticket images selected by a user are processed inside the user’s browser for OCR and are not uploaded to a LottoLens PH application server. The OCR library and supporting files may be loaded from a third-party content delivery network.

Result data

The site downloads static JSON files containing public lottery results. No account is required to use the checker.

Advertising and analytics

This starter build contains only an advertising placeholder. If Google AdSense, analytics, consent-management, or other third-party services are enabled, update this policy to describe cookies, identifiers, vendors, purposes, retention, and user choices that actually apply to your deployment.
