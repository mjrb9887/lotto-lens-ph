A small utility for checking Philippine Lotto tickets.

LottoLens PH is an independent, open-source web tool designed around a common task: quickly comparing the numbers printed on a physical ticket with published draw results.

Why a static site?

The core app is HTML, CSS, and JavaScript so it can be deployed on GitHub Pages with a custom domain and very little infrastructure. Ticket OCR happens in the browser, while a scheduled GitHub Action can refresh static result data.

What it supports

The starter build supports Lotto 6/42, Mega Lotto 6/45, Super Lotto 6/49, Grand Lotto 6/55, and Ultra Lotto 6/58. It does not sell tickets, process payments, or submit bets.

Independence

This project is not affiliated with or endorsed by the Philippine Charity Sweepstakes Office. Game names are used to identify the public lottery games and their published results.
